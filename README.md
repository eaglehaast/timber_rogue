# Timber Rogue

Минималистичный браузерный рогалик про валку деревьев. Вид от первого лица, в руках цепная пила, задача — уронить дерево туда, куда надо.

## Как валить

- Подходишь к стволу — на коре появляется оранжевый прицел: куда ляжет пропил. Направление задаёт взгляд, высоту — куда смотришь на стволе.
- Пропилов можно сделать сколько угодно. Если прицел почти совпал с начатым пропилом, он прилипает к нему и пила продолжает тот же пропил.
- Когда несрезанной древесины (недопила) остаётся меньше 20% сечения, дерево перекидывается через недопил — в ту сторону, куда недопил смещён от оси. Правильно: подпил со стороны падения, потом валочный пропил с обратной стороны навстречу ему.
- Схема в углу — сечение ствола сверху: светлое — недопил, тёмное — выпиленное, оранжевая линия — прицел, зелёная черта — цель.
- Упало в зелёный сектор (±10°) — «ЗБС», мимо — «ФУУ», на тебя — «ПРИШИБЛО».

Управление: WASD — ходить, Shift — бежать, мышь — смотреть, ЛКМ (зажать) — пилить, R — новое дерево.

## Запуск

Сборки нет: Three.js лежит в `vendor/`, игра — обычные файлы. Нужен любой статический сервер (модули не грузятся с `file://`):

```
npx http-server .
```
